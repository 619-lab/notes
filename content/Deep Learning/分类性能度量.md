# 分类性能度量

### 准确率

* 假设只有两类样本，即正例和负例。 表中 AB 模式，第二个符号代表预测，第一个表示预测结果为 True or False。
<table>
	<tr >
	    <td rowspan="4"><center>实<br>际<br>类<br>别</center></td>
	    <td colspan="4"><center>预测类别</center></td>
	</tr>
	<tr>
	    <td></td><td>正</td><td>负</td><td>总计</td>
	</tr>
	<tr>
	    <td>正</td><td>TP</td><td>FN</td><td>P(实际为正)</td>
	</tr>
	<tr>
	    <td>负</td><td>FP</td><td>TN</td><td>N(实际为负)</td>
	</tr>
</table>

* 分类准确率（accuracy）： accuracy= （TP+TN）/（P+N）


## 精确率和召回率
* 精确率（precision）& 召回率（recall）是二分类问题常用的评价指标。    
precision = TP /（TP+FP）    recall = TP / P

* 精确率反映了判定的正例中真正正例的比重。
* 召回率反映了总正例中被模型正确判定正例的比重。医学领域也叫做灵敏度（sensitivity）。
